# VST — Mixture Instrument Factory

Stemless-first open-source integration for instrument timbre cloning from a mixed recording. The implementation lives on the `feat/stemless-instrument-factory` development branch and is **not** a tested VST3 release.

Uses the official [Point-and-Play](https://github.com/User-tian/Point-and-Play) project and exports playable SFZ sample libraries. GPU model inference and VST3 compilation need separate validation. No copyrighted audio or pretrained weights are stored here.
